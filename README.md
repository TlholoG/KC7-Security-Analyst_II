# 🔐 KC7 Security Analyst II — Cybersecurity Investigations

A practical cybersecurity investigation portfolio documenting my progression through **KC7 Cyber's Security Analyst II training**.

This repository builds on the investigation and Kusto Query Language (KQL) skills developed during **Security Analyst I**, extending them into areas including **networking, ransomware-as-a-service, supply-chain security, and industrial control systems (ICS)**.

The repository contains investigation notes, KQL queries, case analysis, and supporting material developed throughout the exercises.

---

## 🎯 Objectives

The main objectives of this level are to:

* Build on foundational security investigation skills.
* Apply KQL to more complex investigation scenarios.
* Develop practical networking knowledge relevant to security operations.
* Investigate ransomware and **Ransomware-as-a-Service (RaaS)** scenarios.
* Explore supply-chain security risks.
* Understand security considerations surrounding Industrial Control Systems (ICS).
* Develop structured investigative reasoning.
* Document evidence, findings, and conclusions.
* Improve the ability to connect technical activity with a broader security incident.

---

## 🔎 Investigation Areas

The repository currently contains work covering several areas of cybersecurity analysis.

### Networking Concepts

The networking module introduces concepts that are important when analysing security events and understanding communication between systems.

Topics include concepts relevant to:

* Network communication
* Hosts and endpoints
* Network traffic
* Infrastructure relationships
* Security investigations involving network activity

Understanding networking provides an important foundation for interpreting security telemetry and investigating suspicious communication.

---

### Ransomware & Ransomware-as-a-Service

The repository includes investigation work related to ransomware and the **Ransomware-as-a-Service (RaaS)** model.

The investigation explores how ransomware operations can involve multiple actors, services and infrastructure rather than being limited to a single attacker or piece of malware.

This work helps connect technical security events with the broader structure of modern cybercrime operations.

---

### Supply Chain Security

The supply-chain investigation focuses on how compromise or malicious activity can affect organisations through relationships with third-party systems, software, vendors or infrastructure.

This introduces a broader perspective on cybersecurity risk beyond individual endpoints.

---

### Industrial Control Systems (ICS)

The repository also introduces **Industrial Control Systems**, expanding the investigation environment beyond traditional enterprise IT systems.

This provides exposure to the security considerations involved when investigating environments where technology interacts with physical processes and operational infrastructure.

### Analytical Reasoning

The investigations require more than simply finding an answer.

The general process is:

```text
Investigation Question
        ↓
Identify Relevant Data
        ↓
Develop KQL Query
        ↓
Analyse Results
        ↓
Correlate Evidence
        ↓
Form Hypothesis
        ↓
Validate Findings
        ↓
Document Conclusion
```
